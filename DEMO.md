# Демонстрация AI Sana — до пяти минут

Статус: сценарий для репетиции. Живой AI пока не прошёл приёмку, см. docs/VERIFICATION.md.
Режим показа озвучивать честно. Заглушка проверяет механику продукта без AI.

## Подготовка

Запустить `sana` с заранее собранным frontend. Открыть адрес, показанный сервером.
Выбрать «Бизнес». Для чистого показа использовать новый SANA_DB, не удалять старую БД.
Все сведения и контакты ниже синтетические. Не представлять их как реальный бизнес.

## Сценарий

| Время | Действие |
|---|---|
| 0:00–0:25 | «Новая задача», отрасль «Образование», ввести слабое описание ниже |
| 0:25–1:30 | Запустить анализ; показать карту, основания вопросов и предполагаемый прирост |
| 1:30–2:30 | Ответить на вопросы; показать цитату-источник в карточке и нулевой балл до подтверждения |
| 2:30–3:15 | Дополнить название/контакт, проверить формулировки, подтвердить поля, сохранить; рейтинг растёт |
| 3:15–3:40 | Опубликовать; открыть каталог и показать позицию по рейтингу и доступность слабых задач |
| 3:40–4:15 | «Студент», команда Data Qanat, открыть задачу и отправить отклик |
| 4:15–4:45 | «Бизнес», вручную выбрать команду и подтвердить выполненный тестовый этап |
| 4:45–5:00 | Показать +10 в лидерборде; выбор всегда у бизнеса, рейтинг объясняется кодом |

## Синтетический ввод

Черновик: «Учебному центру нужен помощник для вопросов о курсах. Данных пока нет,
срок — месяц.» Это повод для уточнения, не доказательство противоречия.

- Потребность: «Сократить повторяющиеся ответы администратора на вопросы о расписании курсов.»
- Пользователи: «Будущие слушатели курсов и администраторы учебного центра.»
- Данные: «Уточняем исходное описание: доступен CSV с расписанием и 30 обезличенных вопросов.»
- Ограничения: «Срок прототипа — 4 недели, Python, только публичные учебные данные.»
- Результат: «Веб-прототип помощника по расписанию с передачей неизвестных вопросов администратору.»
- Успех: «Не менее 80% из 30 тестовых вопросов получают ответ со ссылкой на расписание.»
- Консультации: «Бизнес проводит консультацию раз в неделю и отвечает на вопросы в течение двух дней.»
- Контекст (ручное уточнение): «Администраторы учебного центра вручную отвечают на повторяющиеся вопросы о расписании.»
- Название: «Помощник учебного центра».
- Контакт, только вручную: `demo@example.test`.

Отклик: идея — «Соберём помощника по расписанию на предоставленном CSV»;
план — «Проверим данные, создадим прототип и сравним ответы с критериями бизнеса»;
срок — «4 недели»; ссылка — `https://example.test/prototype` (синтетическая).

## Сбой

При ошибке API показать явный статус и выбрать «Продолжить без ИИ». Объяснить, что
это детерминированная заглушка. Показать «Промпт и формат AI» и программное отклонение
неподтверждённого источниками текста. Не выдавать запись или заглушку за текущий AI-запрос.
