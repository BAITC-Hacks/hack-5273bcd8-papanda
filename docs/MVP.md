# Запуск и архитектура

Подробный старт — в README. После `pip install -e ".[test]"` одна команда `sana`
собирает frontend при отсутствии `web/dist` и запускает FastAPI, обслуживающий API
и статический React-интерфейс. После правок frontend выполните `npm run build` в `web`.

## Модули

- `app/contracts.py` — Pydantic-контракты.
- `app/store.py` — SQLite и транзакционное начисление баллов за этап.
- `app/scoring.py` — чистые функции рейтинга.
- `app/catalog.py` — открытый каталог, фильтры и сортировка.
- `app/api/` — HTTP-адаптер, редактирование, подтверждение, публикация и выбор.
- `app/ai/` — новые доменные AI-процессы, ограничения, источники и трасса.
- `web/` — React/Vite; ни ключей, ни вызовов провайдера из браузера.
- `seed/data.json` — явно синтетические данные.
- `scripts/record_demo.py` — действительный сквозной прогон через TestClient.

## Разделение ответственности

Системная логика определяет допустимые переходы, бюджеты и правила источников.
Actor строит мир/кандидатов/вопросы и предлагает цитируемые поля; другая модель Judge
оценивает их. Человек отвечает, редактирует и подтверждает. Рейтинг и каталог работают
без LLM. Ошибка провайдера или валидации отображается как ошибка; продолжение на
заглушке — явный выбор пользователя, а не скрытый фальшивый AI-ответ.

Один активный прогон на задачу, не более двух кругов вопросов и ограниченное число
вызовов/пересмотров. Ожидание человека асинхронное; интерфейс опрашивает состояние.
Прогон после перезапуска сервера не возобновляется; сохранённые карточки и отклики
остаются в SQLite. Запустить новый анализ можно с сохранённых сведений.

## Переменные

| Имя | Назначение |
|---|---|
| `AI_MODE` | `stub` (по умолчанию) или `engine` |
| `SANA_DB` | Путь SQLite, отдельный файл для чистого запуска |
| `HOST`, `PORT` | По умолчанию 127.0.0.1:8000 |
| `OPENAI_API_KEY`, `OPENAI_BASE_URL` | Общие ключ и адрес API |
| `AI_ACTOR_MODEL`, `AI_JUDGE_MODEL` | Разные модели для двух ролей |
| `AI_ACTOR_API_KEY`, `AI_JUDGE_API_KEY` | Необязательные независимые ключи |
| `AI_ACTOR_BASE_URL`, `AI_JUDGE_BASE_URL` | Необязательные независимые адреса |
| `AI_MAX_CALLS` | Бюджет вызовов, не выше жёсткого предела в коде |
| `AI_MAX_SECONDS` | Суммарное время запросов провайдера |
| `AI_RUN_TIMEOUT` | Полный срок прогона, включая ожидание человека |
| `AI_TRACE_DIR` | Каталог настоящих JSONL-трасс, по умолчанию `data/traces` |

Трассы содержат текст задачи и ответов, поэтому исключены из Git вместе с БД.
Никогда не публикуйте `.env` или реальные пользовательские трассы.
`/api/ai/contract` показывает промпт, схемы, пример отклонённого ответа и объяснение.
OpenAPI доступен на `/docs`.

## Ограничения прототипа

Роли демонстрационные, без авторизации. Сервер предназначен для локального показа
на синтетических данных. Нельзя считать его защищённым публичным многопользовательским
сервисом. Рейтинг — набор прозрачных эвристик, а не сертификация качества задачи.
Отдельный механизм рекомендаций необязателен и пока не реализован.
