# hack-5273bcd8-papanda

## AI Sana Challenge Hub (конкурсная реализация)

Работающий MVP находится в разработке. Требования: [TASK.md](TASK.md).
Общие интерфейсы: [CONTRACT.md](CONTRACT.md). Запуск после интеграции:
`pip install -e ".[test]"`, затем `sana` (первый запуск требует Node.js/npm).
Режим без сети: `AI_MODE=stub`; он явно обозначается как демонстрационная заглушка.
Готовая реализация DialecticAI не используется; новый движок пишется с нуля.

Ниже сохранено исходное описание демонстрационного агента организатора.

Небольшой демонстрационный терминальный агент на Python. Он отвечает на
несколько команд и умеет сохранять задачи в локальный файл `tasks.txt`.

## Запуск

Требуется Python 3.10 или новее.

```powershell
python mini_agent.py
```

В чате напишите `помощь`. Доступные команды: `время`, `задача <текст>`,
`задачи` и `выход`.

`tasks.txt` создаётся во время работы и намеренно не хранится в Git.
